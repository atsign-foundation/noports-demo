What you are about to see

Remote access normally needs an open port: a door on the machine that attackers can find and knock on. NoPorts needs no door.

  1. Five small stand-in machines (Docker containers) are already running. One is the device we will log in to. Another is an attacker with a port scanner.
  2. The attacker scans all 65,535 of the device's ports.
  3. We log in to the device over SSH, through NoPorts.
  4. While we are logged in, the attacker scans again.

At each stop you can look inside the machines yourself. Please do.
